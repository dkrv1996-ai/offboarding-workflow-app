# Offboarding Workflow App

## Run locally
### 1) Install dependencies
npm run install:all

### 2) Setup env
- Copy `backend/.env.example` -> `backend/.env`
- Copy `frontend/.env.example` -> `frontend/.env`

### 3) Run dev (backend + frontend together)
npm run dev

## URLs
- Frontend: http://localhost:5173
- Backend: http://localhost:4000

## Login (HR only)
- hr@local.com / Password@123

## Workflow
HR creates request → Manager → Finance → IT → Admin → Final HR → Completed
